# জননী ফার্মেসি (Jononi Pharmacy) - ডিজিটাল ক্যাশ মেমো মেকার

"জননী ফার্মেসি" (Jononi Enterprise And Healthcare) এর জন্য বিশেষভাবে তৈরি মোবাইল-ফার্স্ট ডিজিটাল ক্যাশ মেমো / ইনভয়েস মেকার। এটি সম্পূর্ণ ক্লায়েন্ট-সাইড (HTML, CSS, JavaScript) পরিচালিত, কোনো ব্যাকএন্ড বা সার্ভার ডেটাবেস ছাড়াই ডিভাইসের লোকাল স্টোরেজে সম্পূর্ণ নিরাপদে কাজ করে এবং অফলাইনেও সম্পূর্ণ সচল থাকে।

## লোকাল কম্পিউটারে রান করার নিয়ম

কোনো বিল্ড বা অতিরিক্ত প্যাকেজ ইন্সটল করার প্রয়োজন নেই:
1. রিপোজিটরিটি ক্লোন বা ডাউনলোড করুন।
2. সরাসরি যেকোনো ওয়েব ব্রাউজারে `index.html` ফাইলটি ডাবল ক্লিক করে চালু করুন।
   (অথবা VS Code এর "Live Server" এক্সটেনশন দিয়ে ওপেন করুন)।
3. অথবা `npx serve .` বা `npm run dev` চালাতে পারেন।

## GitHub থেকে Netlify-তে ডেপ্লয় করার সহজ ধাপ

এই প্রজেক্টটি কোনো ব্যাকএন্ড বা জটিল বিল্ড স্টেপ ছাড়াই কাজ করে, তাই খুব সহজেই সরাসরি Netlify-তে ফ্রিতে ডেপ্লয় করা যায়:

### ধাপ ১: GitHub-এ ফাইল আপলোড
1. আপনার [GitHub](https://github.com) অ্যাকাউন্টে লগইন করুন।
2. একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: `jononi-pharmacy`).
3. আপনার কম্পিউটারের সব ফাইলগুলো গিটে কমিট করে পুশ করুন:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Jononi Pharmacy"
   git branch -M main
   git remote add origin https://github.com/আপনার-ইউজারনেম/jononi-pharmacy.git
   git push -u origin main
   ```

### ধাপ ২: Netlify-তে সংযুক্ত ও ডেপ্লয় করা
1. [Netlify](https://www.netlify.com)-এ লগইন করে **"Add new site"** > **"Import an existing project"** নির্বাচন করুন।
2. **GitHub** নির্বাচন করে আপনার `jononi-pharmacy` রিপোজিটরি পছন্দ করুন।
3. সেটিংস অপশনে:
   - **Build command**: সম্পূর্ণ খালি রাখুন (Leave Empty)।
   - **Publish directory**: `.` (ডট দিন অথবা রুট ফোল্ডার রাখুন)।
4. **"Deploy site"** বাটনে ক্লিক করুন।
5. মাত্র ১০ সেকেন্ডের মধ্যে আপনার লাইভ সাইট তৈরি হয়ে যাবে এবং একটি ফ্রি URL (যেমন: `jononi-pharmacy.netlify.app`) পাবেন।

## ফোনে অ্যাপ হিসেবে ইনস্টল করার নিয়ম (PWA Install)

ওয়েবসাইটটি আপনার অ্যান্ড্রয়েড অথবা আইফোনে একটি আসল মোবাইল অ্যাপের মতো ইনস্টল করে ইন্টারনেট ছাড়াই অফলাইনে ব্যবহার করতে পারবেন:

### অ্যান্ড্রয়েড ফোনে (Chrome / Firefox):
1. ক্রোম ব্রাউজারে সাইটের লিঙ্কে প্রবেশ করুন।
2. অ্যাপের উপরের হেডার থেকে সরাসরি **"ইনস্টল"** বাটনে ট্যাপ করুন।
3. অথবা ব্রাউজারের ডানদিকের ৩-ডট (⋮) মেনুতে ট্যাপ করে **"Install app"** বা **"Add to Home screen"** নির্বাচন করুন।
4. এখন আপনার ফোনের হোমস্ক্রিনে "Jononi" নামে ফার্মেসির লোগোসহ আইকন দেখতে পাবেন।

### আইফোন / আইপ্যাডে (Apple Safari):
1. **Safari** ব্রাউজারে সাইটের লিঙ্কটি ওপেন করুন।
2. ব্রাউজারের নিচের মাঝখানে থাকা **Share (শেয়ার)** বাটনে (তীর চিহ্নের আইকন) চাপুন।
3. অপশনগুলো থেকে একটু নিচে স্ক্রোল করে **"Add to Home Screen"** সিলেক্ট করুন।
4. উপরে ডানে **"Add"** এ চাপুন।
5. আপনার হোমস্ক্রিন থেকে এখন সরাসরি অ্যাপের মতো ফুলস্ক্রিনে ব্যবহার করতে পারবেন।
